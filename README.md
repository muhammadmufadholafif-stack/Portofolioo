## 2. Cara Membuka Website

Website ini **100% offline-ready** dan dirancang tanpa modul bundler atau proses build:
1. Buka folder `d:\web abal abal` di File Explorer.
2. Temukan file bernama `index.html`.
3. **Klik dua kali (double click)** pada file `index.html`.
4. Website akan langsung terbuka dan berjalan sempurna di browser (Chrome, Edge, Firefox, Opera, dll).

## 4. Cara Deploy Gratis ke Internet

### Opsi A: Menggunakan GitHub Pages
1. Buat repository baru di akun GitHub Anda: `muhammadmufadholafif-stack`.
2. Upload seluruh file (`index.html`, `css/`, `js/`, `images/`, `cv.pdf`).
3. Masuk ke **Settings > Pages > Branch**, pilih `main` dan folder `/ (root)`, lalu klik **Save**.
4. Website akan aktif di `https://muhammadmufadholafif-stack.github.io/<nama-repo>/`.

### Opsi B: Menggunakan Vercel
1. Buka [Vercel.com](https://vercel.com) dan login dengan akun GitHub Anda.
2. Klik **Add New > Project**, lalu import repository portofolio ini.
3. Klik **Deploy** tanpa perlu mengubah konfigurasi build apa pun.
